- 1.下载地址
```
wget https://artifacts.elastic.co/downloads/elasticsearch/elasticsearch-8.17.1-linux-x86_64.tar.gz
```
- 2.解压
```
tar -zxvf elasticsearch-8.17.1-linux-x86_64.tar.gz
```
- 3.创建用户
```
useradd elastic
chown -R elastic:elastic /opt/elasticsearch-8.17.1
```
- 4.配置 `.yml` 文件
```
cluster.name: elastic-cluster

# ------------------------------------ Node ------------------------------------
node.name: node-0
node.master: true
node.data: true

# ----------------------------------- Paths ------------------------------------
path.data: /opt/elasticsearch-8.17.1/data-node0
path.logs: /opt/elasticsearch-8.17.1/logs-node0

# ----------------------------------- Memory -----------------------------------
bootstrap.memory_lock: true

# ---------------------------------- Network -----------------------------------

network.host: <HOST_IP>
http.port: 9200
transport.tcp.port: 9300

# ---------------------------------- Discovery -----------------------------------
# master 候选节点数量 / 2 + 1
discovery.zen.minimum_master_nodes: 2
# 自动发现节点机制（无需配完所有节点）
discovery.zen.ping.unicast.hosts: ["node0:9203","node1:9203","node2:9203"]
#设置管理本地存储节点的数量
node.max_local_storage_nodes: 4

```

- 5.jvm配置
```
-Xms 20g
-Xmx 20g
## GC
-XX:+UseConcMarkSweepGC
-XX:CMSInitiatingOccupancyFraction=75
-XX:UseCMSInitiatingOccupancyOnly
```

- 6.多个节点启动配置脚本  
start.sh
```
#! /bin/bash
cd /elasticsearch
su es -c"export ES_PATH_CONF=config/node0;bin/elasticsearch -d -p node0.pid"
```
restart.sh
```
#! /bin/bash
cd /elasticsearch
pid=`cat node0.pid`
su es -c `kill -9 $pid`
sleep 5
sh bin/start.sh
```
check_alive.sh
```
A=$(netstat -lntup |grep 9203 |wc -l)
if [ $A -eq 0 ] ;then
   cd /elasticsearch
   sh bin/restart.sh >node0_StartEsLog_`date +%F+%T`.out
```

- 7.访问
```
https://<HOST_IP>:9200/
```
