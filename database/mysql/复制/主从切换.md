## 1.主从数据一致性校验

## 2.设置主库只读,让从库同步完成

设置主库为只读模式，防止切换时数据写入
```
SET GLOBAL super_read_only=1;
SET GLOBAL read_only=1;
```
在主库加锁 
```
FLUSH TABLES WITH READ LOCK
```
备库查看
```
SHOW SLAVE STATUS
```

## 3.从库停止复制,开启Binlog
从库停止复制，关闭只读功能
```
STOP SLAVE
RESET SLAVE ALL
SET GLOBAL read_only=0
SET GLOBAL super_read_only=0
```
开启binglog,配置my.cnf,之后重启生效
```
#skip_log_bin #非备库可以直接关闭binlog功能，否则binlog配置和主库一致
# 开启二进制日志
log-bin=mysql-bin  #binlog文件名，默认就可以
max_binlog_size = 1G  #binlog单个文件大小，可调节（最小值为4096字节，最大值和默认值为1GB）
binlog_format = row  #行模式
binlog_row_image = full  #full （记录所有列）；minimal （仅记录更改的列和标识行所需的列）；noblob （记录所有列，除了不需要的BLOB和TEXT列）
binlog_rows_query_log_events=OFF #默认关闭
binlog_expire_logs_auto_purge=ON #开启指定时间删除binlog
binlog_expire_logs_seconds=604800 #7天
innodb_flush_log_at_trx_commit=2
sync_binlog=1
# 同步复制配置
#log_slave_updates=1
#read_only=1
#event_scheduler=OFF
#master_info_repository=TABLE
#relay_log_info_repository=TABLE
#relay_log_recovery=1
# 多线程复制
#replica_parallel_type=LOGICAL_CLOCK
#replica_parallel_workers=8
#replica_preserve_commit_order=1
```

## 4.切换
从库升级为主库。

主库切换为从库
```
change master to master_host='replication-2',
master_port=3306,
master_user='root',
master_password='<PASSWORD>',
master_auto_position=1;
```
开启复制
```
UNLOCK TABLES;
SET GLOBAL super_read_only=0;
start slave;
```
修改从库配置文件
```
# 同步复制配置
log_slave_updates=1
read_only=1
event_scheduler=OFF
master_info_repository=TABLE
relay_log_info_repository=TABLE
relay_log_recovery=1
# 多线程复制
replica_parallel_type=LOGICAL_CLOCK
replica_parallel_workers=8
replica_preserve_commit_order=1
```
