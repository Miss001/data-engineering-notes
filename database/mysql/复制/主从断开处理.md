# 在线设置忽略复制指定库、表
```
change REPLICATION FILTER REPLICATE_IGNORE_DB=(DB1);
change REPLICATION FILTER REPLICATE_WILD_IGNORE_TABLE=('DB2.TB1','DB2.TB2');
```
# 跳过错误
未开启gtid
```
stop slave;
set global sql_slave_skip_counter=1;
#change master to master_log_file='binlog.000001',master_log_pos=54;(跳到指定位置)
start slave;
show slave status;
```
开启gtid
```
stop slave;
reset master;
set global gtid_purged='9a7812fc-b195-11eb-b5b6-0242ac110003：1-54';
start slave;
```
