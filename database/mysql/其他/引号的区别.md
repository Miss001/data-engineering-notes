## 引号区别

**（1）反引号（`）**

为了区分MYSQL的保留字与普通字符而引入的符号。

一般用在库名、表名、字段名。

例如：

```
select `repository`.`r_step`.`name` from `repository`.`r_step`;

CREATE DEFINER=`repository`@`%` FUNCTION `getText`
```

此时若使用双引号，会提示错误：

<code>You have an error in your SQL syntax; check the manual that corresponds to your MySQL server version for the right syntax to use near '"getText"(id varchar(32)) RETURNS varchar(100) CHARSET utf8mb3 READS SQL DA' at line 1;</code>


**（2）双引号（"）**

用来限定字符串。

例如：

```
select * from repository.r_step where id_step='1';

select * from repository.r_step where id_step="1";
```


当 SQL_MODE=ANSI_QUOTES 时，双引号 （ " ） 的功能更改为类似于反引号 （ ` ）。通常，双引号的功能更类似于单引号（ ' ）。 

例如：

```
select "repository"."r_step"."name" from "repository"."r_step";

select `repository`.`r_step`.`name` from `repository`.`r_step`;

CREATE DEFINER="repository"@"%" FUNCTION "getText";
```


**（3）单引号（'）**

用来限定字符串，通常使用双引号和使用单引号效果是 等价 的。

例如：

```
select * from repository.r_step where id_step='1';
```
