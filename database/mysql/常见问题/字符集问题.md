
## 字符集

**插入数据字符集报错**

版本：mysql8.0.28
操作：使用 kettle6 抽取oracle数据，表输出写入数据。
报错信息：
```
Incorrect string value: '\xF0\x9F\x98\xAD",...' for column 'Content' at row 1
```
**报错排查方式**

查看客户端和服务器的字符集是否一致，都为utf8mb4
```
show variables like '%character%'
```
| Variable_name            | Value   |
| ------------------------ | ------- |
| character_set_client     | utf8mb4 |
| character_set_connection | utf8mb4 |
| character_set_database   | utf8mb4 |
| character_set_filesystem | binary  |
| character_set_results    | utf8mb4 |
| character_set_server     | utf8    |
| character_set_system     | utf8    |

调整 character_set_server 值与客户端一致.然后重启mysql,否则不生效
```
set global character_set_server=utf8mb4
```

查看数据库、表字段的字符集是否为utf8mb4
```
show create table tbname
```
修改字段字符集：
```
alter table tbname modify column_name varchar(20) character set utf8mb4 collate utf8mb4_general_ci;
修改某个字段的字符集编码：alter table table_name change column_name column_name varchar(64) character set utf8mb4 collate utf8mb4_bin not null;
```
