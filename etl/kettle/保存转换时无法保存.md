报错：
repository - error updating batch
repository - ora-00001: 违反唯一主键约束（repository.idx_rsat）

解决：
select * from r_step order by id_step desc;
select * from r_step_attribute order by id_step_attribute desc;

id_step值由kettle生成，当上述两表id_step不一致则会导致无法保存
delete from r_step_attribute where id_step>=:id_step
